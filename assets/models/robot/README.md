# Green Blocky Robot

Second playable character, sharing the same twelve gameplay animations as
Girlypoppums through the canonical 33-bone rig.

## Package layout

- `animations/` — the shared skinless Mixamo FBXs plus `index.json`. Replacing
  a selected file swaps that animation at startup; arrays in the manifest allow
  multiple variants per state.
- `source/model/` — OBJ, MTL, and PBR texture set used by the prep script.
- `robot_prepared.glb` — Godot-ready base mesh + skeleton (generated by the
  prep script).

## Rebuild

From the repository root:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/prepare_robot.py
```

The prep imports the unrigged OBJ, fits the canonical Mixamo armature to its
volume, auto-weights the mesh, splits the geometry into the six detachable limb
slots, and exports a textured base GLB matching the Girlypoppums contract. It is
needed only when the model/rig changes—not when an animation is replaced.
